# واحد من 8 مليارات — لعبة قرارات لنظام أندرويد (Flutter)

لعبة قصصية بالعربية، مستوحاة من فكرة ألعاب محاكاة الحياة المنتشرة على الويب،
لكنها مكتوبة من الصفر هنا ولا تنسخ أي لعبة بعينها:

- في كل جولة تولد شخصية عشوائية: اسم ودولة (مرجحة بحجم السكان تقريبا) وجنس
  وطبقة عائلية، ولا يختار اللاعب شيئا من ذلك.
- تتخذ قرارات الشخصية من الطفولة حتى الموت عبر أحداث عمرية، كل خيار له
  نتيجة وأثر على الصحة والسعادة والذكاء والمال والعلاقات.
- يُبنى سجل حياة كامل، وعند الموت تظهر شاشة النهاية مع ملخص الحياة
  وإمكانية نسخ القصة كاملة ومشاركتها.
- تعمل دون إنترنت، ولا تجمع بيانات، ولا تحتاج أي حزمة خارجية.

## البنية

- `lib/models.dart` — الشخصية والإحصاءات والأحداث والخيارات.
- `lib/data/countries.dart` — 20 دولة بأسماء ذكور وإناث وألقاب.
- `lib/data/events.dart` — أكثر من 45 حدثا مكتوبا عبر مراحل العمر،
  إضافة إلى أحداث عامة عند نفاد المناسب منها.
- `lib/game_engine.dart` — الولادة العشوائية، اختيار الأحداث، تطبيق القرارات،
  العمر المتوقع، والنهاية.
- `lib/screens/` — البداية، اللعب، النهاية.
- `lib/widgets/stat_bar.dart` — شريط إحصاءة.

## التشغيل والبناء

```bash
flutter pub get
flutter run
flutter build apk --release
```

ملف APK الناتج يكون في:

```
build/app/outputs/flutter-apk/app-release.apk
```

## البناء على GitHub Actions

كل دفع إلى فرع `main` يشغّل `.github/workflows/build-apk.yml` تلقائيا:
يفحص الكود، يشغّل الاختبارات، ويبني `app-release.apk`، ثم يرفعه
كـ Artifact باسم `life-8-billion-apk` في صفحة تشغيل الـ Workflow.
حمّله من هناك وثبّته على هاتف أندرويد.

## أفكار تطوير مقترحة

- حفظ الحيوات السابقة وعرض أفضل حياة وأطول عمر.
- صور وخلفيات لكل دولة ومرحلة عمرية بدلا من الإيموجي.
- أحداث موسمية وأحداث نادرة، ونظام إنجازات.
- وضع إنجليزي، أو ترجمة تلقائية للعبة كلها.
